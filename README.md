## 🧩 3 大關卡與 9 個分支線索

### 密室一：【醫院中央藥局－冷鏈與裝置控制室】
- **線索 1-1（冷鏈溫控極限）**：2°C~8°C 冷藏、30°C/30天室溫極限、結凍直接報廢。
- **線索 1-2（注射筆規格與排氣機械）**：每支4劑0.6mL、排氣旋轉聽到2聲喀擦、視窗顯示長線條「─」。
- **線索 1-3（給藥完成判定與安全廢棄）**：拔針顯示「0」、針頭不留筆、卸下針頭投入防穿刺尖銳物收集桶。
- **解鎖獎勵**：獲得【門禁感應磁卡】與【待審核門診處方箋】。

### 密室二：【門診藥局－處方審核與安全防線】
- **線索 2-1（黑框警語與腫瘤風險）**：甲狀腺 C 細胞腫瘤 (MTC) 風險、四大頸部腫瘤通報症狀。
- **線索 2-2（絕對禁忌症處方攔截）**：即時攔截家族有 MTC 病史與 MEN 2 綜合症的危險處方。
- **線索 2-3（適應症與適當對象）**：改善第二型糖尿病血糖；BMI ≥ 30 或 BMI 27~30 合併共病。
- **解鎖獎勵**：獲得【急診臨床諮詢病歷檔案】與【急診諮詢室金屬鑰匙】。

### 密室三：【急診藥事諮詢室－Final Mission】
- **線索 3-1（階梯滴定與維持劑量定位）**：起始 2.5mg 維持4週（非維持量）、每次遞增 2.5mg、上限 15mg。
- **線索 3-2（錯過劑量與改期應變時間軸）**：漏打 4 天 (96小時) 內補打（逾期跳過）、改期最小間隔 3 天 (72小時)。
- **線索 3-3（跨藥物交互作用與雙重給藥防線）**：延遲胃排空避孕藥加強屏障 4 週；與胰島素分開給藥且不可緊鄰。
- **通關獎勵**：醫院大門解鎖升起，成功逃脫並榮獲《醫院臨床藥事衛教專家》認證！

## 🛠️ 技術架構
- **HTML5 Canvas / Viewport**：自適應 16:9 高清醫院場景渲染。
- **Web Audio API 雙核心音訊引擎**：具備懸疑、緊張、急迫感 Procedural BGM 合成器（生理緊張心跳脈動、倒數秒針急迫滴答、D minor 律動低音與 16 分音符電子琶音，隨關卡推進加速壓迫感）以及高科技醫院音效（終端按鍵音、刷卡音、警報鳴響、KwikPen 雙喀擦聲與大門升起音效）。
- **響應式佈局**：支援桌面瀏覽器與平板/手機觸控操作。
- **自給自足獨立部署**：內建專屬醫院冷藏庫、調劑台、急診室與大樓外觀素材。
